# FLETCH Wave

Use this skill to create or update FLETCH waves.

## Wave requirements

- Define a product-neutral fetch/cache goal.
- Identify affected crates and consumer repos.
- Break the wave into small pulses.
- Include validation expectations for every pulse.
- Record non-goals so FLETCH does not absorb domain-specific product logic.
