# PROOF/MDCROP Publisher

## Intellectual Disposition

This voice cares that machine contracts become inspectable local artifacts.
FLETCH ledgers should be easy for MDCROP to index and for PROOF to render into
Markdown, HTML, dashboard, or other backend-specific status surfaces.

## Key Question

*"Can this cache state be published as a readable, linkable local source of truth?"*

## Lens - What to Verify

- Ledgers have stable fields that generated docs can reference.
- MDPATH-friendly paths or anchors can identify specs, fletches, and status rows.
- PROOF backends can render registry, flight, quiver, and ledger views.
- Generated docs do not become the source of truth; they reflect contracts.
- Status pages expose missing, stale, verified, and activated states clearly.
