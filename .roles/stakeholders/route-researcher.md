# ROUTE Researcher

## Primary concerns

- Source catalogs should register FHWA, Census, NBI, HPMS, FAF, and other shafts.
- Archive shafts may extract into many fletches.
- Research runs need clear status for which cached inputs are cited and fresh.
- Local-only GIS sources need to be represented without pretending they are fetchable.
- Generated reports should cite ledger entries, not ad hoc cache paths.
