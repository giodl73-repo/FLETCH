# MDCROP Indexer

## Primary concerns

- FLETCH ledgers should be easy to index as local corpus metadata.
- Status views need verified, stale, missing, orphaned, and broken states.
- Quivers should expose member fletches and provenance after import.
- MDCROP should report FLETCH health without owning fetch execution.
- Stable schemas matter more than pretty prose.
