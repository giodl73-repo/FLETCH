# MDLOOM Publisher

## Primary concerns

- FLETCH contracts should render into Markdown/status/catalog pages.
- MDLOOM backends may generate local URL/version views beyond raw remote URLs.
- MDPATH anchors should make generated docs linkable and durable.
- Generated docs must reflect ledgers and registries, not replace them.
- Backend-specific formatting should stay out of `fletch-core`.
